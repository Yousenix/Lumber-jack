
# 🪓 Lumber Jack

A simple terminal-based game made with Python.

The player controls `@` and tries to avoid the branches while moving through the forest. The game gets progressively challenging as the player continues.

## 🎮 Controls

* `←` / `→` — Move
* `Space` — Start
* `Esc` — Quit

## 🛠️ Built With

* Python
* `msvcrt`
* `random`

## 📌 About

This project was created as a Python practice project to work with keyboard input, game loop, random generation, and basic game logic.
